# Misi-Dialog-Petualangan
Game Misi Dialog Petualangan adalah game edukatif digital untuk melatih siswa melengkapi dialog rumpang dalam cerita fantasi melalui soal pilihan ganda interaktif. Melalui lima soal pilihan ganda, siswa belajar memilih dialog yang sesuai dengan konteks, karakter tokoh, dan alur cerita.
